# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Students submitting assignments, Teachers reviewing and grading work, and Platform Administrators managing users and system health.

## Product Purpose

A comprehensive learning management and task review platform that enables seamless assignment submission, interactive grading, course management, leaderboards, and administrative system monitoring.

## Positioning

An integrated assessment workspace combining multi-panel code review, real-time analytics, and admin database health controls in a unified modern web interface.

## Operating Context

Daily web usage in desktop and mobile environments for academic and training workflows.

## Capabilities and Constraints

- **Student Portal**: Course view, assignment submission, code editing with Monaco editor, leaderboard, activity logs.
- **Teacher Portal**: Assignment review workspace, two-panel grading, student performance analytics, course membership management.
- **Admin Portal**: User management, system settings, database health monitoring and diagnostics.
- **Tech Stack**: React 19, Vite, TypeScript, Tailwind CSS v3, Monaco Editor, Recharts, ASP.NET Core Web API.

## Brand Commitments

Clean, professional, modern design system. Eliminates AI slop design tropes (generic violet/indigo text gradients, poor text contrast on badges/colored backgrounds, outdated bounce animations).

## Evidence on Hand

- Frontend React application in `frontend/src`
- Backend ASP.NET Core Web API in `backend`

## Product Principles

1. **High Information Density**: Present complex data (code, grades, metrics) clearly without overwhelming the user.
2. **Accessible Contrast**: Ensure all badges, status indicators, and text elements meet strict accessibility standards.
3. **Focused Efficiency**: Streamline review and submission workflows with clear visual feedback and actionable controls.
